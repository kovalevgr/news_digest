Microsoft outlines new Zero Trust tools and guidance for securing AI agents and
DevSecOps pipelines, as AI agent adoption expands the enterprise attack surface.

## card

**Що сталося:** Microsoft представила нові інструменти й настанови Zero Trust для захисту AI-агентів і DevSecOps-конвеєрів: AI-перевірки в Zero Trust Assessment Tool, новий DevSecOps-розділ у Zero Trust Workshop та e-book "Zero Trust for AI". Привід — розширення поверхні атаки підприємств через масове впровадження AI-агентів.

**Контекст:** Публікація продовжує серію безпекових анонсів Microsoft: 31 липня 2026 року компанія представила AI-модель для кібербезпеки MAI-Cyber-1-Flash.

**Деталі:**
- Zero Trust Assessment Tool: нові AI-перевірки поруч із SecOps та Infrastructure (на додачу до Identity, Devices, Network, Data); розширені звіти з practitioner-настановами та executive summary; мапінг результатів на framework "First, Then, Next" воркшопу
- Zero Trust Workshop: новий DevSecOps-розділ — 15 груп контролів і 91 задача, від вихідного коду до cloud-деплою; посилений AI-розділ із Microsoft AI Memory framework
- E-book "Zero Trust for AI: Rebuilding security controls for autonomous and agentic systems"
- Patterns and practices: least privilege для AI-агентів, Zero Trust доступ до вихідного коду, безпека AI memory, захист software supply chain
- Аудиторія: security-практики й керівники, інженерні та платформні команди, партнери (програма Frontier Accelerate for Security)
- Конкретних дат preview/GA у статті немає; Microsoft також відзначає статус "Overall Leader" у KuppingerCole Zero Trust Platform Leadership Compass
