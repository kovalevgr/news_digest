OpenAI introduces the Data agent in ChatGPT Work: connect company data and turn questions into interactive dashboards and action using natural language, built from the tools OpenAI itself uses internally to analyze data.

## card

**Що сталося:** OpenAI випускає Data agent у ChatGPT Work — інструмент, що підключається до корпоративних даних і перетворює природномовні запити на аналіз, інтерактивні дашборди та дії.

**Контекст:** Продовжує розширення ChatGPT Work у бік enterprise-аналітики, слідом за GPT-6 Astra та іншими business-орієнтованими релізами цього тижня (ChatGPT for Financial Services вийшов того ж дня).

**Деталі:**
- Підключення до корпоративних джерел даних і контексту компанії
- Перетворення питань на аналіз, дашборди та дії одним запитом природною мовою
- Побудований на тих самих інструментах, якими OpenAI користується внутрішньо для аналізу власних даних
- Доступний через встановлення плагіна Data agent у ChatGPT Work
