NVIDIA announces general availability of cuObject client/server libraries 2.0.0 and a new SCADA Server SDK letting third-party developers build storage servers with standardized APIs and an RDMA wire protocol for accelerated object storage access; the xio-sig consortium expands to cover cuObject alongside cuFile.

## card

**Що сталося:** NVIDIA випустила у загальний доступ бібліотеки cuObject (клієнт/сервер) версії 2.0.0 та новий SCADA Server SDK, що дозволяє стороннім розробникам створювати сервери зберігання даних зі стандартизованими API та RDMA wire-протоколом для прискореного доступу до об'єктного сховища.

**Контекст:** Розширює консорціум xio-sig (раніше — лише cuFile) додаванням cuObject; частина серії інфраструктурних релізів NVIDIA для AI-сховищ.

**Деталі:**
- cuObject client/server libraries: версія 2.0.0, доступна для завантаження
- SCADA Server SDK: новий, дозволяє стороннім розробникам будувати storage-сервери
- Стандартизовані API + RDMA wire-протокол для прискореного доступу до об'єктного сховища
- Консорціум xio-sig розширено: тепер охоплює і cuObject, і cuFile
