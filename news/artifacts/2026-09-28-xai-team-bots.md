## card

**Що сталося:** xAI запускає Team Bots — командні версії Grok Bot з єдиним контекстом, інструментами, обліковими даними та пам'яттю для всієї команди; розмови кожної людини з ботом залишаються приватними. Доступно вже сьогодні у публічній беті для планів Teams та Enterprise.

**Контекст:** розвиток лінійки Grok Bot (запущеної в серпні 2026 як індивідуальні AI-тімейти) у бік спільного, командного використання одного бота кількома людьми. Backfilled: пропущено попередніми прогонами (x.ai блокується на рівні DNS для WebFetch у цьому середовищі; анонімний Jina час від часу відмовляв), підтверджено сьогодні через Jina.

**Деталі:**
- 4 складові Team Bot-а: контекст (файли/інструкції/skills), плагіни (Salesforce, Notion, GitHub — підключаються особисто або централізовано), облікові дані для API без плагінів, пам'ять про вивчене з часом.
- Приклади всередині SpaceXAI: Sales Bot щоранку готує бриф по акаунту з новин/дзвінків/Slack; Engineering Bot веде тікети й запускає Cloud Agents (команда з 5 людей відправляє 100+ PR/день); Marketing Bot перевіряє драфти на відповідність голосу бренду й сам публікує SEO-правки; Data Bot відповідає на запити по 45,000+ таблицях через read-only доступ.
- Приклад клієнта: страхова компанія Harper за 24 години зібрала Team Bot, що заощадив клієнтам понад $120,000 на сотнях полісів.
- Доступ: Slack-інтеграція з окремим handle для кожного бота; публічна бета для Teams та Enterprise вже сьогодні.
