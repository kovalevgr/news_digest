Hugging Face's Merve announces llama.cpp's v1.0.0 release, the reference local-inference engine's first major-version milestone, alongside new Llama desktop apps built on it to lower the barrier to running models locally.

## card

**Що сталося:** Hugging Face (Merve) оголосив реліз llama.cpp v1.0.0 — першу велику версію ключового локального inference-движка — разом із новими десктопними застосунками Llama, побудованими на llama.cpp, щоб спростити запуск моделей локально.

**Контекст:** Реліз подається як підтвердження курсу проєкту — підтримувати всі платформи й типи моделей, залишаючись легким для застосунків, що використовують llama.cpp "під капотом".

**Деталі:**
- Версія: v1.0.0 — перший великий (major) реліз проєкту.
- Супроводжується новими десктопними застосунками Llama на базі llama.cpp.
- Акцент на широкій платформній/модельній підтримці при збереженні легковажності (lean) для застосунків-наступників.
