OpenAI ships ChatGPT Images 2.5, an image generation/editing upgrade with sharper detail, more precise targeted editing, and up to 50% faster generation than Images 2.0; ships alongside new API models GPT-Image-2.5 Flare (fast, general-purpose) and GPT-Image-2.5 Sunburst (higher-precision creative work). ## card

**Що сталося:** OpenAI випустила ChatGPT Images 2.5 — оновлення моделі генерації та редагування зображень із чіткішими деталями, точнішим локальним (targeted) редагуванням та генерацією швидшою на до 50% порівняно з Images 2.0.

**Контекст:** Одночасно OpenAI випускає дві нові моделі для API: GPT-Image-2.5 Flare (швидша, для загальних задач) та GPT-Image-2.5 Sunburst (для точнішої творчої роботи) — продовження лінійки моделей генерації зображень після Images 2.0.

**Деталі:**
- Прискорення генерації: до 50% швидше за Images 2.0
- Покращене точкове (targeted) редагування — можна змінити одну частину зображення, не чіпаючи решту, з кращим збереженням попередніх правок при подальшому уточненні
- Природніше освітлення, багатші текстури, краще збереження ідентичності об'єктів з референсних фото
- Нові інструменти: ChatGPT Sketch (перетворення начерку на зображення), шаблони (постери, мерч), коментарі просто на зображенні для запиту правок
- Для розробників: GPT-Image-2.5 Flare та GPT-Image-2.5 Sunburst доступні через API
