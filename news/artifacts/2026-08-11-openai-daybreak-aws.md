OpenAI and AWS are making Daybreak cybersecurity models (Daybreak Blue, Daybreak Red) available through Amazon Bedrock, giving enterprise security teams access to frontier cyber-defense and vulnerability-research models within their existing AWS environments.

## card

**Що сталося:** OpenAI та AWS роблять моделі Daybreak (кібербезпекова лінійка OpenAI) доступними через Amazon Bedrock. Daybreak Blue дає доступ до фронтирних моделей загального призначення (включно з GPT-5.6 Sol) із запобіжниками під захисну безпекову роботу; Daybreak Red — до вузькоспеціалізованих кібербезпекових моделей для авторизованого дослідження вразливостей, валідації експлойтів і security testing.

**Контекст:** Продовжує партнерство OpenAI–AWS: раніше цього року фронтирні моделі OpenAI та Codex стали загальнодоступні на AWS. Це наступний крок — інтеграція саме кібербезпекової лінійки Daybreak.

**Деталі:**
- Доступ вимагає реєстрації в Daybreak Access (enrollment-форма)
- Після схвалення — доступ через консоль Amazon Bedrock або Responses API (endpoint bedrock-mantle)
- Моделі підтримують: пошук вразливостей, detection engineering, incident response від виявлення до підтвердженого фіксу, відтворення експлойтів, розробку заходів пом'якшення
- Позиціонується як шлях для enterprise-команд використовувати ці моделі в межах уже наявних AWS-процесів security review, governance, access control
