OpenAI introduces GPT‑6 Cyber, a cybersecurity-focused model scoring 48.5% on ExploitGym (up from 32.1% for GPT‑5.6 Cyber, a 51% relative gain) and staying within authorized scope in 99.93–100% of alignment tests; already used to find 948 Linux privilege-escalation exploits and 81 previously unknown Firefox vulnerabilities.

## card

**Що сталося:** OpenAI випустила GPT‑6 Cyber — модель, спеціалізовану на пошуку та виправленні вразливостей, з результатом 48.5% на ExploitGym (було 32.1% у GPT‑5.6 Cyber, +51% відносно) та дотриманням дозволених меж дослідження у 99.93% тестів без deployment-промпта і 100% — з ним.

**Контекст:** Модель уже застосовували для пошуку 948 експлойтів підвищення привілеїв у Linux та 81 раніше невідомої high-severity вразливості у Firefox (Mozilla вже випустила патчі для частини з них). Входить у лінійку Daybreak (Daybreak Blue/Daybreak Red) для верифікованих дослідників безпеки.

**Деталі:**
- ExploitGym: 48.5% (GPT‑6 Cyber) vs 32.1% (GPT‑5.6 Cyber).
- Дотримання меж дослідження: 99.93% без спеціального промпта, 100% із ним.
- 948 експлойтів підвищення привілеїв знайдено в Linux; 81 нова high-severity вразливість у Firefox.
- Команди безпеки Cisco, Calif та CodeRabbit вже використовують модель для дослідження вразливостей і code review.
