Cursor adds realtime voice calls with coding agents — users can describe changes aloud, ask what an agent is doing, and hear progress updates while it works; available in the Agents Window, IDE, web, and iOS app, running on Grok Voice, and distinct from existing speech-to-text dictation.

## card

**Що сталося:** Cursor додав голосові дзвінки в реальному часі з AI-агентами: можна голосом описувати зміни, запитувати, що робить агент, і чути оновлення прогресу під час роботи.

**Контекст:** Доступно у вікні агентів, IDE, вебверсії та iOS-застосунку; працює на базі Grok Voice. Відрізняється від звичної диктовки (speech-to-text) в полі чату — це повноцінний голосовий діалог, а не лише введення тексту голосом.

**Деталі:**
- Платформи: Agents Window, IDE, web, iOS app.
- Голосовий рушій: Grok Voice.
- Функції: голосові запити на зміни, запитання про поточний статус роботи агента, голосові оновлення прогресу.
