xAI brings Grok 4.6 to Microsoft Foundry, letting organizations evaluate, deploy and govern the model alongside other frontier models with enterprise security controls.

## card

**Що сталося:** xAI зробила Grok 4.6 доступним на Microsoft Foundry — платформі для оцінки, деплою та керування моделями в enterprise-середовищі.

**Контекст:** Grok 4.6 — флагманська модель xAI для довготривалих агентів; це чергова інтеграція після появи Grok 4.6 в GitHub Copilot та інших платформах.

**Деталі:**
- Foundry дозволяє тестувати Grok 4.6 поряд з іншими фронтир-моделями під конкретні ворклоади
- Розгортання керованих ендпоінтів з enterprise-контролем безпеки та управління
- Цільові сценарії: агенти для коду, інженерні копайлоти, дослідницькі асистенти, корпоративна автоматизація
- Доступно через каталог моделей Foundry (ai.azure.com/catalog/models)
