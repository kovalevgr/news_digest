Perplexity launches the Agent API, a single programmable endpoint unifying web search, URL fetching, code execution, MCP connections, and finance/people search into one retrieval pipeline; all existing Sonar customers are upgraded to an Agent API preset, with Sonar staying available for 45 days before retirement.

## card

**Що сталося:** Perplexity випустила Agent API — єдину програмовану точку входу, що об'єднує веб-пошук, завантаження URL, виконання коду, MCP-з'єднання та пошук по фінансах/людях в один конвеєр отримання даних. Усіх клієнтів Sonar одразу оновлюють на пресет Agent API.

**Контекст:** Раніше Sonar пропонував фіксований набір моделей (Sonar, Sonar Pro, Sonar Reasoning Pro, Sonar Deep Research) — кожен рівень був окремим продуктовим рішенням. Agent API збирає це в один програмований шар поверх архітектури "Search as Code".

**Деталі:**
- Шість пресетів: fast, low, medium, high, xhigh, wide-research — від швидкості/вартості до глибини
- Відповідність старим тарифам: sonar→fast, sonar-pro→low, sonar-reasoning-pro→medium, sonar-deep-research→high; xhigh — новий рівень для відкритих агентних задач
- Sonar залишається доступним 45 днів, потім Agent API стає єдиною поверхнею; контрактні зобов'язання з Sonar діють до кінця поточного терміну
- Пресети переналаштовуються з кожним релізом флагманської моделі — той самий виклик today і за пів року відображає актуальний стан
- Кожен параметр пресету можна перевизначити вручну
- Інструменти: веб-пошук, fetch URL, code sandbox, MCP-сервери, фінансовий пошук, пошук людей
