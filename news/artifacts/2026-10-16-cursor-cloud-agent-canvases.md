Cursor lets cloud agents build interactive canvases shareable via link, and launches a beta Environments API for programmatically creating and managing agent cloud environments; environments now support up to 300 repositories and load 5x faster.

## card

**Що сталося:** Cursor додає можливість хмарним агентам створювати інтерактивні canvas (візуальні артефакти роботи), якими команда може поділитися посиланням на готовий результат.

**Контекст:** Паралельно запускається бета-версія Environments API — програмного інтерфейсу для створення й керування хмарними середовищами, в яких працюють агенти.

**Деталі:**
- Хмарні середовища агентів тепер підтримують до 300 репозиторіїв.
- Великі середовища завантажуються у 5 разів швидше.
- Environments API — у статусі бета.
