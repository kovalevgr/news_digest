Cursor launches two bots for Teams/Enterprise plans: Rollouts, which monitors deployment health per environment, and Security Review, which flags exploitable vulnerabilities on pull requests.

## card

**Що сталося:** Cursor випускає два нові боти для планів Teams/Enterprise: Rollouts стежить за станом кожного розгортання в кожному середовищі, а Security Review виявляє експлуатовні вразливості у pull request'ах.

**Контекст:** Обидва інструменти вбудовуються у наявний workflow розгортання та код-рев'ю коду Cursor, розширюючи автоматизацію з написання коду на його безпечне постачання в продакшн.

**Деталі:**
- Rollouts: моніторинг здоров'я розгортання окремо по кожному середовищу
- Security Review: пошук експлуатовних вразливостей безпосередньо в pull request'ах
- Доступність: плани Teams та Enterprise
- Пропонується безкоштовний 10-денний пробний період використання
