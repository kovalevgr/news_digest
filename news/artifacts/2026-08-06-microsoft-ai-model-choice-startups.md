Microsoft publishes a startup architecture blueprint for deploying Fireworks AI on
Microsoft Foundry, expanding the range of AI models startups can choose from on the
platform.

## card

**Що сталося:** Microsoft оголосила загальну доступність (GA) Fireworks AI на Microsoft Foundry і опублікувала архітектурний blueprint для стартапів: як розгорнути високопродуктивний низьколатентний інференс відкритих моделей безпосередньо в Azure. Це розширює вибір AI-моделей для стартапів на платформі.

**Контекст:** Пост вийшов у блозі Microsoft for Startups і продовжує серію свіжих анонсів Microsoft навколо AI-платформи та інфраструктури — напередодні (2026-08-05) компанія представила Zero Trust-інструменти для захисту AI-агентів і DevSecOps.

**Деталі:**
- Fireworks AI на Microsoft Foundry — «now generally available»; serverless-модель інференсу з оплатою за токени.
- Blueprint: Foundry + Fireworks (моделі, governance, billing в одній control plane), Azure Container Apps (застосунок/API), Container Registry, Key Vault; опційно Azure Monitor, Azure Cache for Redis, API Management.
- Підтримка A/B-тестування кількох варіантів моделей; fine-tuning через Fireworks Training і bring-your-own weights; згадується опція Data Zone Standard pricing.
- Стартапи можуть отримати до $150,000 кредитів, застосовних до Fireworks-деплойментів і супутньої Azure-інфраструктури; provisioned throughput units (PTU) кредитами не покриваються.
