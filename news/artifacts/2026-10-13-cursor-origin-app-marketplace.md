Cursor opens the Origin App Marketplace with 20+ integrations (Cloudflare, Linear, Sentry, Socket Security among them) for deployments, CI, code review, security and monitoring, and opens public submissions to any dev-tools team building against the Origin API.

## card

**Що сталося:** Cursor відкриває Origin App Marketplace — маркетплейс інтеграцій для платформи Origin з понад 20 застосунками для розгортання, CI, перегляду коду, безпеки й моніторингу.

**Контекст:** Серед наявних інтеграцій — Cloudflare, Linear, Sentry, Socket Security. Маркетплейс також відкрито для публічних заявок від будь-якої команди, що розробляє інструменти для розробників.

**Деталі:**
- Понад 20 інтеграцій вже доступні на старті.
- Щоб додати застосунок: зібрати його на базі Origin API, зробити публічним і подати заявку зі slug, тегами та демо-відео.
- Cursor публікує застосунок у маркетплейсі після перевірки.
