Grok 4.6 is now live in GitHub Copilot across cloud agents, the Copilot CLI, and the VS Code IDE, and remains available via the xAI console at $2/M input and $6/M output tokens.

## card

**Що сталося:** Grok 4.6 став доступний у GitHub Copilot — у хмарних агентах, Copilot CLI та VS Code IDE. Деякі бізнес/enterprise-акаунти повинні вручну увімкнути модель у налаштуваннях Copilot.

**Контекст:** Продовжує серію інтеграцій моделей xAI у сторонні продукти (Grok 4.5 вже був у GitHub Copilot раніше) і йде одразу за релізом Grok 4.6 (2026-08-12).

**Деталі:**
- Доступність: cloud agents, Copilot CLI, VS Code IDE — вибір моделі "Grok 4.6" у picker'і
- Enterprise/бізнес-акаунти можуть потребувати ручного увімкнення в налаштуваннях
- Ціна через xAI console: $2 за млн вхідних токенів, $6 за млн вихідних токенів
