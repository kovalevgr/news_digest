Cursor Cloud Agents can now start new projects without a connected GitHub repo — work begins immediately in a live browser preview, with an Origin repo created automatically to save later.

## card

**Що сталося:** Cursor дозволила Cloud Agents починати нові проєкти без підключеного GitHub-репозиторію — розробка стартує одразу, з живим превʼю в браузері.

**Контекст:** Спирається на систему репозиторіїв Origin (запущену 17 серпня); прибирає бар'єр підключення акаунта на старті прототипування.

**Деталі:**
- Вибір "Start from scratch" у виборі репозиторію
- Cursor автоматично створює репозиторій Origin у фоні
- Кнопка "Create repo" для збереження роботи з власною назвою пізніше
- Живе превʼю просто в браузері; інтеграція з Vercel для публікації на живому URL
- Доступно з 27 серпня 2026 на cursor.com/agents
