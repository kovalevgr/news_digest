Perplexity launches Portable Computer, a version of Perplexity Computer built with NVIDIA that runs entirely on-device (NVIDIA DGX Spark, soon RTX GPU PCs), keeping private data local with optional cloud escalation.

## card

**Що сталося:** Perplexity випустила Portable Computer — локальну версію Perplexity Computer, розроблену з NVIDIA, яка працює повністю на пристрої користувача.

**Контекст:** Побудована на NVIDIA DGX Spark (згодом і на RTX GPU ПК); окрема технічна публікація того ж дня деталізує спільний дизайн моделі й harness для локальної роботи.

**Деталі:**
- Працює на Qwen 3.8 27B або PPLX 27B (post-trained версія Qwen) на DGX Spark
- Робота на пристрої не витрачає кредити; приватні дані лишаються локально
- За дозволом користувача — ескалація до хмари для складніших завдань
- Найближчим часом — підтримка NVIDIA RTX GPU PC
