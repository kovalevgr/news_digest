Cursor launches Origin, a code-hosting platform in early beta for all paid plans, letting developers create and manage repositories directly inside Cursor with integrated pull-request management and bidirectional GitHub sync.

## card

**Що сталося:** Cursor запустив Origin — платформу для хостингу коду в ранній бета-версії для всіх платних планів, що дозволяє створювати й керувати репозиторіями прямо всередині Cursor з інтегрованим управлінням pull request'ами та GitHub-синхронізацією.

**Контекст:** Логічне розширення продукту Cursor у бік повноцінної платформи розробки (після нещодавнього запуску "builds" для швидшого старту хмарних агентів); Origin позиціонується як хостинг, "розрахований на масштаб агентів".

**Деталі:**
- Хостинг репозиторіїв: нова вкладка Codebase для створення репо й push коду
- GitHub-інтеграція: синхронізовані репо співіснують з репо на Cursor, двостороннє оновлення PR і коментарів у реальному часі
- Управління PR: перегляд таймлайну, рев'ю diff, коментування, злиття
- Інтеграція з агентами: агенти можуть відповідати на питання про код, вносити зміни, оновлювати PR, пушити гілки
- Екосистема застосунків: доступні інтеграції з Vercel (preview-деплойменти), Depot, Buildkite (CI/CD)
- Доступність: рання бета для всіх платних планів
