Anthropic donates Agent Skills (its open standard for giving AI agents specialized knowledge/workflows), the Agent Skills name/logo, GitHub org, and agentskills.io domain, to the Linux Foundation's Agentic AI Foundation (AAIF, co-founded with Block and OpenAI); over 70 platforms (ChatGPT, Cursor, GitHub Copilot, VS Code) have integrated it, ~1M skills published, ~280M installs.

## card

**Що сталося:** Anthropic передає стандарт Agent Skills (відкритий формат для надання AI-агентам спеціалізованих знань і робочих процесів) разом з назвою, логотипом, GitHub-організацією та доменом agentskills.io до Agentic AI Foundation (AAIF) — проєкту Linux Foundation, заснованого Anthropic разом з Block і OpenAI.

**Контекст:** Agent Skills опубліковано як відкритий стандарт у грудні 2025 року; це вже другий внесок Anthropic до AAIF після Model Context Protocol (MCP). Фонд описано як "нейтральний дім для стандарту" — організації можуть використовувати чи долучатися до розробки без вступу в AAIF.

**Деталі:**
- Понад 70 платформ інтегрували стандарт, зокрема ChatGPT, Cursor, GitHub Copilot, VS Code.
- Опубліковано близько 1 млн skills, встановлено майже 280 млн разів.
- Підтримку вестимуть інженери Anthropic, Google, OpenAI та інших компаній як приватні особи; провідні мейнтейнери — David Soria Parra та Mahesh Murag.
- Дорожня карта: версійні релізи, формальний процес пропозицій, рекомендації з безпеки для авторів і установників skills.
